# 1.Vypočtěte limity funkcí:
## a)
$$
\begin{align}
\lim_{ x \to \infty } \frac{(3x-2)(3x+2)}{(4x+1)^{2}}=\lim_{ x \to \infty } \frac{9x^{2}+6x-6x-4}{16x^{2}+8x+1}=\frac{9}{16}
\end{align}
$$
## b)
$$
\begin{align}
\lim_{ x \to 0 } \frac{\sin 2x}{3x}=\frac{2}{3}
\end{align}
$$
## c)
$$
\begin{align}
\lim_{ x \to 3 } \frac{x^{2}-x-6}{x^{2}-9} =\lim_{ x \to 3 } \frac{(x-3)(x+2)}{(x-3)(x+3)}=\lim_{ x \to 3 } \frac{x+2}{x+3}=\frac{5}{6}
\end{align}
$$
## d)
$$
\begin{align}
\lim_{ x \to \infty } \frac{(x+1)^{3}}{2x^{3}-7}=\lim_{ x \to \infty } \frac{x^{3}+\dots}{2x^{3}+\dots}=\frac{1}{2}
\end{align}
$$
## e)
$$
\begin{align}
\lim_{ x \to 0 } \frac{\sin2x-2\sin x}{\sin ^{2}x}=\lim_{ x \to 0 } \frac{2\sin x\cos x-2\sin x}{1-\cos ^{2}x}=\lim_{ x \to 0 } \frac{2\sin x(\cos x-1)}{(1-\cos x)(1+\cos x)}=\lim_{ x \to 0 } -\frac{2\sin x}{1+\cos x}=0
\end{align}
$$
