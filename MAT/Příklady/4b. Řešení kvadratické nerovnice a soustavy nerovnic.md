# 2. Řešte početně i graficky : $2x^{2} +x-15 \geq 0$.
$$
\begin{align}
2x^{2} +x-15 \geq 0 \\
2x^{2} +x-15 = 0 \\
x\in \{ -3, 2.5  \} \\
2>0 \\
P=(-\infty,-3\rangle \cup \langle 2.5,\infty)
\end{align}
$$
```tikz
\begin{document}
\begin{tikzpicture}[scale=0.3]
    % Oříznutí, aby graf nepřetékal přes osy
    \clip (-20, -20) rectangle (20, 20);

    % Mřížka
    \draw[very thin, gray!20] (-20,-20) grid (20,20);

    % Osy
    \draw[->] (-20,0) -- (20,0) node[right] {$x$};
    \draw[->] (0,-20) -- (0,20) node[above] {$y$};

    % Funkce y = x^-2
    % Kreslíme dvě větve odděleně, abychom se vyhnuli nule
    \draw[red, thick, samples=100, domain=-3:2.5] plot (\x, {2*(\x)^2+\x-15});
    \draw[cyan, thick, samples=100, domain=-4.5:-3] plot (\x, {2*(\x)^2+\x-15});
    \draw[cyan, thick, samples=100, domain=2.5:4] plot (\x, {2*(\x)^2+\x-15});

    % Popisky
    \node[below left, font=\scriptsize] at (0,0) {0};
    
    % Průsečíky
    \draw[white, fill=cyan] (-3,0) circle (2pt);
    \node[below left] at (-3,0) {[-3,0]};
    
    \draw[white, fill=cyan] (2.5,0) circle (2pt);
    \node[below right] at (2.5,0) {[2.5,0]};
    
\end{tikzpicture}
\end{document}
```
