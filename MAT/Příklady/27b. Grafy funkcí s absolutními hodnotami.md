# Sestrojte grafy funkcí, určete $D(f)$ a $H(f)$ .
## 4. $f_{4} :y= | x^{2} +2x-3 |$
$$
\begin{align}
D(f_{4}) = \mathbb R \\
H(f_{4}) = \langle0,\infty)
\end{align}
$$
```tikz
\begin{document}
\begin{tikzpicture}[scale=1.2]
    % Oříznutí, aby graf nepřetékal přes osy
    \clip (-5.5, -1) rectangle (5.5, 6);

    % Mřížka
    \draw[very thin, gray!20] (-4,-0.5) grid (4,5.5);

    % Osy
    \draw[->] (-4.2,0) -- (4.2,0) node[right] {$x$};
    \draw[->] (0,-0.7) -- (0,5.7) node[above] {$y$};

    % Funkce y = x^-2
    \draw[cyan, thick, samples=100, domain=-4:-3] plot (\x, {(\x)^2+2*\x-3});
    \draw[cyan, thick, samples=100, domain=-3:1] plot (\x, {-((\x)^2+2*\x-3)});
    \draw[cyan, thick, samples=100, domain=1:4] plot (\x, {(\x)^2+2*\x-3});


    % Popisky
    \node[below left, font=\scriptsize] at (0,0) {0};
    
    
\end{tikzpicture}
\end{document}
```
## 7. $f_{7} :y= | x^{2} -5x+2 |$
$$
\begin{align}
D(f_{7}) = \mathbb R \\
H(f_{7}) = \langle0,\infty)
\end{align}
$$
```tikz
\begin{document}
\begin{tikzpicture}[scale=1.2]
    % Oříznutí, aby graf nepřetékal přes osy
    \clip (-2.5, -1) rectangle (7.5, 6);

    % Mřížka
    \draw[very thin, gray!20] (-1,-0.5) grid (7,5.5);

    % Osy

    \draw[->] (0,-0.7) -- (0,5.7) node[above] {$y$};

    \draw[cyan, thick, samples=100, domain=-1:0.43845] plot (\x, {(\x)^2-5*\x+2});
    \draw[cyan, thick, samples=100, domain=0.43845:4.56155] plot (\x, {-((\x)^2-5*\x+2)});
    \draw[cyan, thick, samples=100, domain=4.56155:7] plot (\x, {(\x)^2-5*\x+2});


    % Popisky

\end{tikzpicture}
\end{document}
```
