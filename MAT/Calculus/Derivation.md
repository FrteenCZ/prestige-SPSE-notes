# Basic rules

| If $f$ is a function of the independent variable $x$, the derivative of the function is defined by the equation: | $$f^{\prime}(x)=\lim_{h \rightarrow 0} \frac{f(x+h)-f(x)}{h}$$                                                                                                                                                                                                                                                                                                           |
| :--------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![](../../Images/Pasted%20image%2020260217161736.png)                                                            | $f(x+h)-f(x)$ is the height of the triangle. <br> $h$ is the base length of the triangle. $$\text { The slope is: } \quad \tan \alpha=\frac{f(x+h)-f(x)}{(x+h)-x}$$<br> So when $h$ tends to zero the expression become: $$f^{\prime}(x)=\lim _{h \rightarrow 0} \frac{f(x+h)-f(x)}{h}$$ <br> This is the slope of the tangent line to the function $f(x)$ at point $x$. |
| **Chain rule** <br>$f(x)=u(g(x))$                                                                                | $$f'(x)=u'(g) \cdot g'$$                                                                                                                                                                                                                                                                                                                                                 |
| **Multiplication rule**: <br>$f(x)=g(x) \cdot u(x)$                                                              | $$f^{\prime}(x)=g^{\prime} u+g u^{\prime}$$                                                                                                                                                                                                                                                                                                                              |
| **Quotient rule**: <br>$f(x)=\dfrac{g(x)}{u(x)}$                                                                 | $$f^{\prime}(x)=\frac{g^{\prime} \cdot u-g \cdot u^{\prime}}{u^2} \quad u \neq 0$$                                                                                                                                                                                                                                                                                       |
| **Reciprocalrule**: If $f(x)=\dfrac{1}{u(x)}$ then $f^{\prime}$ is:                                              | $$f^{\prime}(x)=-\frac{u^{\prime}}{u^2} \quad u \neq 0$$                                                                                                                                                                                                                                                                                                                 |
| **Addition rule**: If $f=f(x)$ and $g=g(x)$ and $a$ and $b$ are real numbers then $(a f+b g)^{\prime}$ is:       | $$(a f+b g)^{\prime}=a f^{\prime}+b g^{\prime}$$                                                                                                                                                                                                                                                                                                                         |
| **Constant rule**: If $f(x)$ is a constant then $f^{\prime}$ is:                                                 | $$f^{\prime}=0$$                                                                                                                                                                                                                                                                                                                                                         |
| If $f=f(x)$ then all the following notations for derivatives are valid:                                          | .   $\text{First derivative:} \quad \dfrac{d f}{d x} \equiv f^{\prime} \equiv \dot{f} \equiv f_x$ <br>$\text{Second derivative:} \quad \dfrac{d^2 f}{d x^2} \equiv \dfrac{d}{d x}\left(\dfrac{d f}{d x}\right) \equiv f^{\prime \prime} \equiv \ddot{f} \equiv f_{x x}$                                                                                                  |
