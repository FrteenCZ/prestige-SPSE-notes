= **jsou průhledná stejnorodá tělesa, které jsou ohraničená​ dvěma kulovými, anebo kulovou a rovinnou optickou plochou.​**

Čočky mohou být:​
- spojky,​
- rozptylky.​

## Spojné čočky (spojky) - konvexní​
Když je index lomu čočky $n_2$ větší než index lomu okolního prostředí $n_1$, $n_{1}<n_{2}$
![[Lenses_convex.svg]]
- pak jsou spojky uprostřed nejsilnější.​

## Rozptylné čočky (rozptylky) - konkávní​
Pokud je index lomu čočky $n_2$ větší než index lomu okolního prostředí $n_1$, $n_2 > n_1$
![[Lenses_concave.svg]]
- Pak jsou rozptylky uprostřed nejtenčí.​
