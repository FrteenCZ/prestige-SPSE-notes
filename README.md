# 📚 prestige-SPSE-notes
Tento repozitář obsahuje moje osobní poznámky z Technického lycea (SPŠE), které jsem si psal během studia. Jsou určené pro studenty, kteří si chtějí učivo zopakovat, doplnit, nebo se na něj připravit z trochu jiné perspektivy.


## 📝 Formát
Poznámky jsou psané v **Markdownu** a optimalizované pro zobrazení v [**Obsidianu**](https://obsidian.md/). Díky tomu:

- jsou podporované **matematické zápisy (LaTeX)**,
- fungují vložené **obrázky a grafy**,
- využívají se **interní odkazy** pro lepší orientaci mezi tématy.

📌 _Pro správné zobrazení doporučuji použít Obsidian nebo jiný nástroj, který podporuje rozšíření Markdownu._

## 📂 Struktura
Každý předmět má svůj vlastní adresář s logickým členěním do témat. Součástí jsou i odkazy mezi jednotlivými poznámkami a případně doplňkové materiály (obrázky, grafy, příklady apod.).
