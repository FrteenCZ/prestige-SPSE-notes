# Unární
Používají **jeden operand**:

| Operátor | Popis     | Příklad          |
| -------- | --------- | ---------------- |
| `+`      | plus      | `+x`             |
| `-`      | mínus     | `-x`             |
| `++`     | inkrement | `x++` nebo `++x` |
| `--`     | dekrement | `x--` nebo `--x` |
| `!`      | negace    | `!true`          |

---

# Binární
Používají **dva operandy**:

| Kategorie   | Operátory         |
| ----------- | ----------------- |
| Aritmetické | `+ - * / %`       |
| Porovnávací | `== != < > <= >=` |
| Logické     | `&&               |
| Přiřazovací | `= += -= *= /=`   |

---

# Ternární operátor
Zkrácený zápis `if-else`:
```java
int max = (a > b) ? a : b;
```
